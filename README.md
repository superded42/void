#  chest(сундук) — цифровой склад с конспектами (форк Quartz)

Это **форк** генератора статических сайтов **[Quartz](https://github.com/jackyzha0/quartz)** (автор: [jackyzha0](https://github.com/jackyzha0)). 

Если ты хочешь **использовать этот репозиторий как основу для своих заметок** или **помочь мне в наполнении, если ты "свой"**, эта инструкция для тебя.

---

##  Быстрый старт (для новичков)

### 1. Что понадобится

- **Git** – для клонирования репозитория.
- **Node.js** (версия 22 или новее) и **npm** (устанавливаются вместе с Node.js). Проверь версии:

```bash
    node -v   # должно быть v22.x.x
    npm -v    # должно быть 10.x.x или выше
```

- **Любой текстовый редактор** – рекомендую [Obsidian](https://obsidian.md) (он идеально совместим с Quartz), но подойдёт и обычный блокнот, VSCode и т.д.

---

### 2. Получение доступа к репозиторию

Чтобы ты мог добавлять свои файлы в этот репозиторий, есть два способа:

#### Вариант А: Стать участником (Collaborator) – для постоянного доступа

> **Этот вариант даёт вам право напрямую пушить изменения в репозиторий.**

1. Свяжись со мной (например, через GitHub: [@superded42](https://github.com/superded42)) и попроси добавить вас в collaborators.
2. После того как я добавлю тебя, ты получишь приглашение по электронной почте (или в уведомлениях GitHub). Прими его.
3. Теперь ты можешь клонировать репозиторий и пушить изменения напрямую.

#### Вариант Б: Форкнуть репозиторий – для собственной копии

> **Этот вариант подходит, если ты хочешь создать свою собственную версию сайта на основе моей.**

1. Нажми кнопку **Fork** в правом верхнем углу на странице репозитория.
2. Создай свою копию (форк) в своём аккаунте GitHub.
3. Клонируй её к себе и работай с ней как с отдельным проектом.

---

### 3. Клонирование репозитория (если ты уже collaborator)

```bash
    git clone https://github.com/superded42/chest.git
    cd chest
```

Если вы используешь SSH (рекомендуется для удобства), то клонируй так:

```bash
    git clone git@github.com:superded42/chest.git
    cd chest
```
---

### 4. Установка зависимостей

В папке проекта выполни:

```bash
    npm install
```

Это установит все необходимые пакеты для работы Quartz (около 500). Подожди 1–2 минуты.

---

### 5. Проверка локальной работы сайта

Чтобы увидеть сайт на своём компьютере, выполни:

```bash
    npx quartz build --serve
```

После сборки открой браузер и перейди по адресу: [http://localhost:8080](http://localhost:8080). Ты увидишь сайт с моими заметками.

## Как добавлять свои заметки

Все файлы с содержимым находятся в папке **`content/`**. Ты можешь свободно редактировать существующие файлы или создавать новые.

### Правила именования и формата

- Файлы должны иметь расширение **`.md`** (Markdown).
- Ты можешь использовать стандартный синтаксис Markdown, а также расширения Obsidian:
  - **Вики-ссылки:** `[[Название заметки]]` – создаёт ссылку на другую заметку.
  - **Теги:** `#физика` – группирует заметки.
  - **LaTeX-формулы:** `$E=mc^2$` (строчная) или `$$...$$` (блочная).
  - **Диаграммы Mermaid:** с использованием блоков `mermaid`.
  - **Встраивание Excalidraw:** `![[рисунок.excalidraw]]` (если у тебя есть рисунки в этом формате).

### Создание новой заметки

```bash
    nano content/новая-заметка.md   # или используй любой текстовый редактор
```

Пример содержимого:

```markdown
    ---
    title: Законы сохранения
    tags: [физика, механика]
    ---
    
    # Законы сохранения
    
    ## Импульс
    
    $$ p = mv $$
    
    ## Энергия
    
    $$ E_k = \frac{mv^2}{2} $$
```

После сохранения файла ты можешь проверить его отображение локально (см. шаг 5).

##  Как отправить изменения на GitHub (пушить)

Если ты collaborator, ты можешь пушить напрямую в основную ветку (обычно `v5` или `main` – я скажу, какая используется).

```bash
    git add content/   # или конкретный файл
    git commit -m "Добавлена заметка о квантовой физике"
    git push origin v5   # замените v5 на актуальную ветку
```

После пуша автоматически запустится GitHub Actions, который соберёт сайт и опубликует его на GitHub Pages. Сайт обновится в течение 1–2 минут.

##  Дополнительные полезные команды

- **Очистка кэша и пересборка:**

```bash
    rm -rf .quartz-cache public
    npx quartz build
```

- **Ручной деплой** (если автоматический не работает):

```bash
    npx quartz build
    cp -r public/* .
    git add .
    git commit -m "Ручной деплой"
    git push origin v5
```

- **Запуск в режиме наблюдения** (автопересборка при изменениях):

```bash
    npx quartz build --serve --watch
```

##  Работа с Obsidian (рекомендуется)

1. Установи Obsidian.
2. Откройте папку `chest` как хранилище (File → Open folder as vault).
3. Теперь ты можешь редактировать заметки с поддержкой всех возможностей Obsidian: вики-ссылки, теги, предпросмотр формул, плагины (Excalidraw, Desmos и т.д.).
4. После редактирования файлы автоматически сохраняются, тебе нужно только запушить их в Git.
