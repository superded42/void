#  chest (сундук) — цифровой склад с конспектами (форк Quartz)

Это **форк** генератора статических сайтов **[Quartz](https://github.com/jackyzha0/quartz)** (автор: [jackyzha0](https://github.com/jackyzha0)). 

Если ты хочешь **использовать этот репозиторий как основу для своих заметок** или **помочь мне в наполнении, если ты "свой"**, эта инструкция для тебя.

---
### 1. Получение доступа к репозиторию

Чтобы ты мог добавлять свои файлы в этот репозиторий, есть два способа:

#### Вариант А: Стать участником (Collaborator) – для постоянного доступа

> **Этот вариант даёт тебе право напрямую пушить изменения в репозиторий.**

1. Свяжись со мной (например, через GitHub: [@superded42](https://github.com/superded42).
2. Теперь ты сможешь клонировать репозиторий и пушить изменения напрямую, для этого существует специализированный [туториал](./instructions/navigation.md).

#### Вариант Б: Форкнуть репозиторий – для собственной копии

> **Этот вариант подходит, если ты хочешь создать свою собственную версию сайта на основе моей.**

1. Нажми кнопку **Fork** в правом верхнем углу на странице репозитория.
2. Создай свою копию (форк) в своём аккаунте GitHub.
3. Клонируй её к себе и работай с ней как с отдельным проектом.

##  Структура папок (основные)

```
chest/
├── content/ # ← заметки (это главная папка)
│ ├── index.md # главная страница
│ ├── подраздел/
│ │ ├── index.md # страница раздела
│ │ └── конспект.md
│ └── ...
├── quartz/ # движок Quartz (не трогай, если не уверен)
├── quartz.config.ts # конфигурация сайта
├── package.json # зависимости
└── .github/ # настройки GitHub Actions (для автодеплоя)
```
