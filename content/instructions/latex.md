### Что такое LaTeX?

**LaTeX**  — это система для подготовки документов, которая широко используется в науке и образовании для создания формул, уравнений и математических выражений.

---
### Что такое LaTeX Suite?

**LaTeX Suite** — это плагин для Obsidian, который превращает набор LaTeX-формул в быстрый и интуитивный процесс.

---

##  Установка

1. Obsidian → **Настройки** (иконка шестерёнки в левом нижнем углу).
2. **Сообщество** → **Community plugins**.
3. **"Включить плагины сообщества"**.
4. **"Обзор"** и ввести в поиске `Latex Suite`.
5. **"Установить"**, затем **"Включить"**.

---

##  Базовые настройки (рекомендуется)

| Функция                   | Что делает                                                                      |
| ------------------------- | ------------------------------------------------------------------------------- |
| **Auto-fraction**         | `1/2` → автоматически превращается в `\frac{1}{2}`                              |
| **Conceal**               | Скрывает LaTeX-разметку, показывая красивые символы (например, `\sqrt{}` → `√`) |
| **Auto-enlarge brackets** | Автоматически делает скобки большими: `(` → `\left(`                            |
| **Matrix shortcuts**      | Упрощает редактирование матриц                                                  |

##  Основные приёмы работы

### 1. Сниппеты (главная фишка)

Сниппеты — это короткие команды, которые превращаются в полноценные LaTeX-конструкции.

| Команда → Результат                                                         | Описание                         |
| --------------------------------------------------------------------------- | -------------------------------- |
| `dm` → `$$ $$`                                                              | Войти в режим блочной формулы    |
| `xsr` → `x^{2}`                                                             | Квадрат                          |
| `sq` → `\sqrt{ }`                                                           | Квадратный корень                |
| `x/y` + `Tab` → `\frac{x}{y}`                                               | Дробь                            |
| `sin @t` → `\sin \theta`                                                    | Синус с греческой буквой         |
| `par` + `Tab` + `f` + `Tab` + `x` + `Tab` → `\frac{\partial f}{\partial x}` | Частная производная              |
| `dint` + `Tab` → `\int_{0}^{2\pi}`                                          | Определённый интеграл (пошагово) |

**Важно:** после многих сниппетов нужно нажать **`Tab`**, чтобы завершить подстановку и перейти к следующему полю.

### 2. Авто-дробь (Auto-fraction)

| Ввод                                 | Результат                                |
| ------------------------------------ | ---------------------------------------- |
| `x/`                                 | `\frac{x}{}` (курсор внутри знаменателя) |
| `(a + b(c + d))/`                    | `\frac{a + b(c + d)}{}`                  |
| После ввода знаменателя нажать `Tab` | Выйти из дроби                           |

##  Дополнительные полезные сниппеты

| Команда → Результат | Описание              |
| ------------------- | --------------------- |
| `@a` → `\alpha`     | Греческая буква альфа |
| `@b` → `\beta`      | Греческая буква бета  |
| `@t` → `\theta`     | Греческая буква тета  |
| `sr` → `^{2}`       | Квадрат               |
| `cb` → `^{3}`       | Куб                   |
| `//` → `\frac{}{}`  | Дробь (пустая)        |
| `mk` → `$ $`        | Пустой строчный режим |

##  Полный пример: как быстро написать формулу

Допустим, нужно написать:

$$ \int_{0}^{2\pi} \sin \theta \, d\theta $$

**Вот как это делается с LaTeX Suite:**

1.  `dm` → появится `$$ $$`
2.  `dint` → появится `\int_{  }`
3.  `2pi` → появится `2\pi` 
4.  `Tab` → переход к следующему полю
5.  `sin @t` → появится `\sin \theta`
6.  `Tab` → переход к `d\theta`
7.  `@t` → появится `\theta`

---

##  Важные замечания

- **Сниппеты работают только в математическом режиме** (внутри `$...$` или `$$...$$`).
- **Tab** — главная клавиша для подтверждения сниппетов и навигации по полям.
- Все стандартные сниппеты можно посмотреть и изменить в настройках плагина.
