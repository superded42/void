# Что такое obsidian?
Obsidian - бесплатное приложение для ведения заметок в формате `.md`(markdown). Из-за сторонних плагинов в obsidian возможно огромное количество различных функций:
написание формул с использованием [LaTeX](./latex.md), отображение графиков функций, чертеж рисунков и много другое.

## Установка
### Windows:
1. Официальный сайт: https://obsidian.md.
2. Download for Windows
3. Установка по старинке
### Linux (пример Arch Linux):
```bash
sudo pacman -S obsidian
```

## Первый запуск
1. Открыть папку как хранилище
2. Выбрать chest/

Напомню, что основные изменения мы вносим в папку content
