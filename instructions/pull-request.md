# Чтобы слить новую ветку с основной нужно:

## I. Создание Pull Request на GitHub
### Вариант А: интерфейс GitHub
1. После пуша новой ветки зайди в репозиторий:
   https://github.com/superded42/chest
2. Pull request -> New pull request 
3. Выбор:
   * base: `v5`
   * compare: `newbranch/mechanics`
4. Заголовок и описание
5. `Create pull request` 
### Вариант Б: Через GitHub CLI
```bash
gh pr crate --base v5 -- head newbranch/mechanics -- title "Добавлен новый конпект" --body "Описание изменений"
```
## II. Сливание
1. Так как настроено **требование успешных проверок**, то необходимо дождаться, пока GitHub соберет сайт.
2. Если все галочки зелёные, то нажать одну из кнопок слияния:
   * `Create a merge commit` - стандартное слияния всех коммитов.
   * `Squash and merge` - все коммиты RP сольются в один (рекомендовано для чистоты истории).
   * `Rebase and merge`- перебазирает все коммиты на `v5`.
## III. Удаление ветки:
   `Delete branch` - на этой же странице GitHub. Это удалит ветку с глобального репозитория.
   ```bash
   git branch -D newbranch/mechanics # удалить локальную ветку
   ```
## IV. Обновление  локальной `v5`
```bash
git checkout v5
git pull origin v5
```
## V. Дополнение:
После всех этих действий запрос на слияние веток поступит автору резпозитория. Необходимо дождаться его разрешения, после чего ветки будут слиты и сайт обновиться.
